# Crop Nexa Seeds — Static Website Starter

## Run locally
1. Keep this folder structure unchanged.
2. Open `index.html` directly in Chrome/Edge/Firefox.
3. For the smoothest local experience, optionally run a tiny local server:
   - VS Code: install "Live Server" and choose **Open with Live Server**
   - Or Python: `python -m http.server 5500`
4. Visit `http://localhost:5500`.

## Files
- `index.html` — complete page structure/content
- `styles.css` — responsive visual design
- `script.js` — mobile menu, crop filters, product modal and mailto enquiry form
- `assets/` — supplied Crop Nexa product/reference images

## Before production
Replace any placeholder/general copy with the company's legally approved:
- About/mission text
- product agronomy/specifications
- certifications and test results
- dealer/distributor list
- privacy policy / terms
- final phone, email and address
- social links

## Important
The contact form is intentionally backend-free. On submit it opens the visitor's email client addressed to `support@cropnexaseeds.com`. For production, connect the form to your preferred backend/form service.
